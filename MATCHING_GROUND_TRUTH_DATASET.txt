# AI Matching Benchmark: Full Ground Truth Dataset (20 Scenarios)

This document contains the complete set of test cases used to evaluate the AI Matching and Suitability Explanations. Each case consists of a User Profile, an Opportunity, and the Human "Ground Truth" (GT) expectations.

---

### Case 1: Technical Depth
- **User**: Python, Docker, AWS (Team: DevOps)
- **Opp**: Cloud Infrastructure Engineer (AWS, Terraform)
- **GT Score**: 90-100%
- **GT Reasoning**: Strong AWS fit, slight gap in Terraform.

### Case 2: Semantic Match (Dev vs Eng)
- **User**: Developer, React (Team: Product)
- **Opp**: Frontend Engineer (React)
- **GT Score**: 85-95%
- **GT Reasoning**: Excellent design alignment and Figma expertise.

### Case 3: Partial Match (50%)
- **User**: Python (Team: Data)
- **Opp**: DS Internship (Python, ML)
- **GT Score**: 40-60%
- **GT Reasoning**: Solid Python foundation but lacks Machine Learning experience.

### Case 4: No Match
- **User**: Writing (Team: Marketing)
- **Opp**: DBA (SQL, Azure)
- **GT Score**: 0-10%
- **GT Reasoning**: No correlation between writing and database administration.

### Case 5: Team Match Only
- **User**: Admin (Team: HR)
- **Opp**: HR Event (Coordination)
- **GT Score**: 20-40%
- **GT Reasoning**: Highly suited HR team context, even if specific skills differ.

### Case 6: Misleading Keyword (Route)
- **User**: Driver, Route Planning (Team: Logistics)
- **Opp**: API Route Planner (Python)
- **GT Score**: 0-15%
- **GT Reasoning**: Poor match; Logistics route planning is not IT routing.

### Case 7: Skill in Description, not List
- **User**: Figma (Team: Design)
- **Opp**: Designer (Tag: Art, Desc: "Needs Figma pro")
- **GT Score**: 70-90%
- **GT Reasoning**: Strong match due to specific tool mention in the description.

### Case 8: Seniority Mismatch
- **User**: Junior Python (Team: Eng)
- **Opp**: Principal Architect (10+ years exp)
- **GT Score**: 20-40%
- **GT Reasoning**: Solid tech base but significantly lacks the required seniority.

### Case 9: Niche Tool Match

### Case 10: Soft Skill Dominance

### Case 11: Technical Cross-over
